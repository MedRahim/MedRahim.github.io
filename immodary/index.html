Télécharger pour Android

APK · Android 8+ · ~35 Mo · Connexion Internet requise

Comment installer

  1. Appuyez sur Télécharger pour Android ci-dessus.
  2. Ouvrez le fichier téléchargé (ImmoDary-release.apk).
  3. Si Android le demande, autorisez l’installation depuis le navigateur ou « sources inconnues ».
  4. Appuyez sur Installer, puis ouvrez Immo Dary.
